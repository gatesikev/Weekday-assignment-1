Kigali Explorer Website
Overview

Kigali Explorer is an informative and user-friendly website that showcases the best things to do, places to eat, and attractions in Kigali, Rwanda. The site is designed to help visitors explore the city with ease and discover restaurants, cafes, outdoor activities, and attractions.

The project demonstrates mastery of HTML and CSS , including layout, styling, lists, tables, multimedia elements, and responsive design.
